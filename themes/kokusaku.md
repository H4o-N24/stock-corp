### 原発回帰の最新動向（2026年5月）

| 項目 | 状況 |
|------|------|
| 政策転換 | 2022年〜：運転延長・新設容認へ方針転換 |
| 関西電力 | 高浜・美浜が再稼働済み。電力各社で最も進んでいる |
| 中部電力 | 浜岡原発の再稼働審査中 |
| 東京電力 | 柏崎刈羽原発：地元同意待ち・再稼働観測 |
| 次世代炉（SMR） | 三菱重工・日立GEが開発参入。政策支援予定 |

**GX推進法（2023年成立）** で原発の最大活用が国策に。AIデータセンターの電力需要増が原発再稼働を加速させる背景に。
