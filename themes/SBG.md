## テーマの概要

孫正義が「AGI（汎用人工知能）時代の覇者になる」と宣言し、ARMをAI時代の中核資産と位置づけてあらゆる投資をAI・ロボティクスへ集中。SBG株は「孫正義に賭ける株」であり、保有NAV（純資産価値）に対する大幅なディスカウントで買えるのが醍醐味。

| 指標 | 数値 |

| 時価総額 | 約20兆円（2026年5月時点） |

| NAVディスカウント | 約30〜40%（構造的なディスカウント） |
| 有利子負債（純） | 約4兆円 |

## ARM Holdings（ARM）── SBGの最重要資産

### 基本情報

| 項目 | 数値 |
|------|------|
| 上場市場 | NASDAQ（2023年9月IPO） |
| SBG保有比率 | 約90% |
| Q4 FY2026売上 | **$1.49B（前年比+20%）** |
| Q4 FY2026純利益 | **+49%（大幅増益）** |
| ロイヤリティ収入成長 | AI・データセンター採用拡大で加速 |

### ARMのビジネスモデル

```
【設計IP（命令セット・CPUコア）のライセンス販売】
  ↓ ライセンス料（Licensing）
  NVIDIA・Apple・Qualcomm・Amazon・Google等が利用
  ↓ 出荷後のロイヤリティ（Royalty）
  チップ1個当たり数セント〜数十ドルが入る
```

- **AI時代の「通行料収入」モデル**：どのAI半導体が勝ってもARM IPは使われる
- **データセンター進出加速**：AWS Graviton（NVIDIA Grace CPUもARM）でサーバー用途拡大
- **Armv9アーキテクチャ**：旧Armv8比でロイヤリティ単価が2倍

### 2031年中期目標（2025年10月発表）

| 目標 | 内容 |
|------|------|
| チップ売上ロイヤリティ | **$15B**（2026年実績から約3倍） |
| EPS目標 | **$9超** |
| TAM（市場機会） | **$1.5兆**（スマホ・PC・データセンター・自動車） |

**成長性：** ★★★★★　ARMなしでAI半導体は設計できない時代が来ている

## SBGの財務構造とリスク

### 資産構造（2026年5月推計）

```
【主要資産】
  ARM Holdings      ：時価 約20兆円（SBG保有分）
  OpenAI            ：評価  約5〜6兆円（含み益）
  Vision Fund portfolio：約10兆円
  その他投資・現金    ：約2〜3兆円
  ─────────────────
  NAV合計推計        ：約35〜40兆円

【負債】
  有利子負債（純）  ：約4兆円
  ─────────────────
  株主価値（理論）  ：約30〜35兆円
  時価総額          ：約20兆円
  → ディスカウント率：約30〜40%
```

### 主なリスク

| リスク | 内容 |
|--------|------|
| レバレッジ | 有利子負債4兆円。金利上昇・ARM株価下落でLTV悪化 |
| ARM株価依存 | NAVの半分以上がARM。ARM株が下がればSBGも連動 |
| OpenAI IPO遅延 | 上場が遅れると含み益が実現しない |
| 非上場投資の流動性 | Vision Fundの投資先は急に換金できない |
| 孫正義リスク | 個人の意思決定への依存度が高い |

## 投資戦略的な見方

### SBG株（9984）の評価方法

- **NAV比較法が基本：** NAV（推計）×（1-ディスカウント率）で妥当株価を算出
- 現在のディスカウント30〜40%は歴史的に縮小・拡大を繰り返す
- ARM上昇→NAV上昇→SBG上昇の連動が最もシンプルなシナリオ

### チェックすべき指標

| 指標 | 意味 |
|------|------|
| ARM株価（NASDAQ:ARM） | SBGのNAVを直撃する最重要指標 |
| OpenAI評価額・IPO動向 | 含み益実現タイミングに影響 |
| LTV（Loan-To-Value） | 借入/資産。25%超えると警戒水準 |
| Vision Fund評価額 | 四半期ごとに開示 |

### 短期（1〜2年）
- **ARM業績の継続的成長確認**が前提。Armv9の普及でロイヤリティ単価上昇中
- Stargate建設進捗・OpenAI IPO観測が株価カタリストに

### 中期（3〜5年）
- OpenAI上場が実現すれば評価益が現金化→NAVディスカウント縮小
- ヒューマノイドロボット（Figure AI・1X）の商用化で新たな評価軸
