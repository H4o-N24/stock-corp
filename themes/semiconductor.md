### 半導体市場の規模感

| 指標 | 数値 |
|------|------|
| 世界半導体市場（2026年） | **約$6,500億**（過去最高水準） |

## ファウンドリ（製造）

### TSMC ── ファウンドリ世界1位・AI半導体の独占製造拠点

| 指標 | 数値 |
|------|------|
| 世界ファウンドリシェア | **約60%** |
| 売上（2025年） | $900億超（過去最高） |
| 設備投資（2025年） | $350億（前年比+42%） |
| 2nm量産 | **2025年下期〜2026年量産拡大** |
| 日本工場（熊本） | TSMC Japan 第1工場稼働済み。第2工場建設中 |

**注力領域：**
- **CoWoS（チップ・オン・ウエハー）**：NVIDIAのBlackwellを製造
- **2nm（N2プロセス）**：AppleのA19・NVIDIAの次世代GPUに採用見込み
- **熊本工場（JASM）**：ルネサス・ソニーと合弁。国策支援で補助金1兆円超

**成長性：** ★★★★★　AI半導体はTSMC製造なしに成立しない。構造的に代替不可

---

### Samsung Electronics ── メモリ世界1位・ファウンドリも手掛ける

| 項目 | 数値 |
|------|------|
| DRAM世界シェア | 約40% |
| HBM（高帯域幅メモリ） | HBM3e量産・HBM4準備中 |
| ファウンドリ | GAA（Gate-All-Around）2nm技術で差別化狙い |
| 設備投資2026年 | **HBM向け2倍増産計画** |

**課題：** NVIDIA向けHBMはSK Hynixが主力供給。SamsungのHBM品質がNVIDIA基準を通過できるかが焦点

---

### Intel ── 半導体老舗、ファウンドリ再建中

- Intel Foundry（旧IDM）：外部顧客向け製造を本格化
- 18Aプロセス（2025〜2026年）：TSMC 2nmに対抗できるか注目
- 米国内製造にこだわる（CHIPS法補助金の最大受益者）
- **成長性：★★★**　ファウンドリ転換は試練の途中

## 装置・材料（製造を支えるインフラ）

### ASML（ASML）── EUV露光装置の絶対独占者

| 指標 | 数値 |
|------|------|
| EUV装置シェア | **世界100%（競合なし）** |
| High-NA EUV（次世代） | 1台$350M超・2026年から本格出荷 |
| 受注残高 | $400億超（2〜3年分） |

**ASML抜きで最先端半導体は作れない。**  
2nm以降はHigh-NA EUVが必須。ASML 1社が全ファウンドリのボトルネック。

**成長性：** ★★★★★　ただし株価は既に高評価。長期保有向き。

---

### 東京エレクトロン（8035）★ ── 日本の装置最大手

| 指標 | 数値 |
|------|------|
| 世界シェア（コーター）| 約90%（フォトレジスト塗布装置） |
| 世界シェア（エッチャー）| 約20%（上位3社） |
| 成長性 | ★★★★★ |

- TSMCの2nm投資・Rapidusに連動して装置需要が拡大
- どのチップメーカーが勝ってもTELの装置は必要（中立的受益者）
- **米輸出規制リスク：** 中国向け制限で売上の約30%に影響

---

### レーザーテック（6920）── EUVマスク検査で世界独占

- EUV露光に使うフォトマスクの欠陥検査装置でシェアほぼ100%
- AIデータセンター向け最先端チップの需要増→検査装置需要増
- **高PER・高ボラ注意。** 成長期待が株価に織り込まれやすい
- **成長性：** ★★★★

---

### ディスコ（6146）── ダイシング（切断）装置の世界首位

- シリコンウエハをチップに切り出す「切断装置」で世界トップ
- AI半導体では積層・パッケージングが複雑化→切断精度が重要
- 安定した収益構造。高利益率。
- **成長性：** ★★★★

---

### SCREEN HD（7735）── 洗浄装置で国内上位

- ウエハ洗浄装置。前工程での欠陥を除去する重要工程
- TSMCの熊本工場・Rapidus向け需要が期待される
- **成長性：** ★★★

## 材料・ウエハ

### 信越化学（4063）★保有 ── シリコンウエハ世界1位

| 指標 | 数値 |
|------|------|
| シリコンウエハ世界シェア | **約30%（首位）** |
| フォトレジスト | EUV向け超高純度品で高シェア |
| PVC（塩ビ）| 北米トップ。収益の安定柱 |

**AIデータセンターのチップ増→ウエハ需要増→信越化学の受益。**  
半導体市況が上向けば業績は素直に拡大する。PVCで利益の下支えあり。

---

### SUMCO（3436）── シリコンウエハ世界2位

- 信越化学と並ぶウエハ大手（合計シェア50%超）
- 300mmウエハが主力。AI半導体は300mmが標準
- **成長性：** ★★★

## AI半導体競争（GPU・カスタムチップ）

### NVIDIA（NVDA）── AI GPU覇者・事実上の独占

| FY2026（2025年1月期） | 数値 |
|---------------------|------|
| 売上 | $1,302億（前年比+114%） |
| データセンター部門 | $1,155億（全体の88%） |
| Blackwell世代 | 出荷開始・超旺盛な需要 |
| Rubin世代 | 2026年後半〜出荷予定 |

**CUDAエコシステム：** 10年以上かけて構築したソフトウェア資産。競合がハードを真似ても、CUDAエコシステムの移行コストが参入障壁。

---

### AMD（AMD）── NVIDIA対抗の2番手

- MI300X（AI GPU）：主にクラウド各社が採用。コスパ面でNVIDIAに競争
- ROCm（ソフトウェア）：CUDA対抗だが生態系は劣勢
- **成長性：** ★★★（NVIDIAの独走続くが一定シェア確保）

### カスタムAI半導体（ASIC）

| 企業 | 製品 | 採用 |
|------|------|------|
| Google | TPU v5 | Google Cloud AI |
| Amazon | Trainium2・Inferentia | AWS |
| Meta | MTIA | Meta AI |
| Microsoft | Maia 100 | Azure AI |

NVIDIAへの依存を減らしたいBig TechがASIC開発を加速。ただしNVIDIAのシェアに大きく食い込むには時間がかかる。

## HBM（高帯域幅メモリ）

AIのGPUに積載される超高速・大容量メモリ。AI推論・学習に不可欠。

| 企業 | 状況 |
|------|------|
| **SK Hynix（韓国）** | NVIDIAへのHBM供給で世界首位。HBM3e主力供給中 |
| **Samsung** | HBM3e・HBM4量産計画。NVIDIAの品質審査通過が課題 |
| **Micron（MU）** | HBM3e量産開始。Samsung・SKに追いつく段階 |

**HBMは品薄が続き、高い利益率を保ちやすい。** 日本からの直接投資は難しいが、装置（TEL・ディスコ）・ウエハ（信越化学）経由で恩恵。

## 投資戦略的な見方

### 短期（1〜2年）確度高い
- **東京エレクトロン（8035）**：Rapidus・TSMC熊本・AI投資の装置需要直結
- **アドバンテスト（6857）**：HBMテスト需要。NVIDIAサプライチェーンの恩恵
- **NVIDIA（NVDA）**：AI GPU独占。Blackwellへの旺盛な需要継続

### 中期（3〜5年）
- **TSMC（TSM）**：AIデータセンター投資が続く限り成長。2nm移行で単価上昇
- **ASML（ASML）**：High-NA EUV移行で長期受注残。代替不可
- **Rapidus関連（TEL・信越化学）**：2027年量産化が実現すれば一段の需要

### 保有銘柄との関係
- **信越化学（4063）** ★保有中：ウエハ需要増の直接受益者
- **ソシオネクスト（6526）** ★保有中：カスタム半導体設計でAI向け受注拡大
